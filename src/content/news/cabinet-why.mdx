开过小店的都知道那笔账：房租、转让费、人工、水电，每个月还没开张，几万块先出去了。熬到回本要一年，中间但凡选址失误，转让费直接打水漂。

自助零食柜、无人货柜走的是另一条路——把"店"缩成一台设备。凌晨两点想吃泡面，传统店接不住这单，柜子照收。不用请人看着，一两个平方就能放，库存销量手机上看，缺了货顺路去补一下。

当然，柜子不是万能的，**位置选对才有得赚**。这篇就说说哪些地方值得放。

## 哪些场景被验证过，潜力不错

挑点位有个朴素的逻辑：一群出不去或者懒得动的人，待在一个买零食不方便的地方。照着这个逻辑看，下面这些场景都是被市场验证过的：

| 场景 | 消费特点 | 主力商品 |
| ---- | -------- | -------- |
| 写字楼 / 办公室 | 下午茶、加班场景，复购率高 | 饮料、咖啡、零食、面包 |
| 工厂 / 园区 | 人群集中，夜班需求旺盛 | 饮料、泡面、功能饮料 |
| 学校 / 公寓 | 封闭人群，消费频次高 | 零食、饮料、日用品 |
| 健身房 | 运动完就想喝点什么 | 功能饮料、蛋白棒、水 |
| 酒店 / 网吧 | 深夜消费，冲动购买 | 饮料、泡面、零食 |
| 社区 / 楼栋 | 图个方便，家庭客群 | 粮油日用、饮料、零食 |

举两个具体的感受：工厂下午三四点和夜班交接的时候，功能饮料是一箱一箱走的；写字楼下午茶时间，电梯口那台柜子前经常排队。反过来，人流大但大家匆匆路过的地铁口、步行街，柜子的表现往往一般——人是不缺，但没人停下来。

## 和开一家小店比，账是这样的

| 对比项 | 传统便利店 | 自助货柜 |
| ------ | ---------- | -------- |
| 启动成本 | 数万到数十万 | 单柜成本低得多 |
| 每月房租 | 整间铺面 | 1-2 平米位置费，有的场地还免 |
| 人工 | 至少 1-2 名店员 | 不需要 |
| 营业时长 | 12-16 小时 | 24 小时 |
| 试错成本 | 高，选错址很难翻身 | 低，点位不行可以挪柜 |

所以很多老板的做法是：**先放一台柜子试试水**。一个点位两三个月数据就出来了，行就加柜，不行就挪走，试错代价和开个店完全不是一个量级。

## 三种玩法，看你手里有什么

**手上有点位，但不想操心经营的。** 比如你认识工厂老板、能进园区、有学校资源——可以由设备方提供柜机、负责运营补货，你收点位分成。这种模式你只出资源，其他都不用管。

**想自己干，缺点位的。** 那就租或者买柜机，服务商给你选点建议、设备和后台系统，供应链也对接好，你负责补货，赚多少都是你的。

**资源多，想干大的。** 手里有一片本地渠道，能铺一批柜子的，建议直接看 [代理合作模式](/agent)，按生意的做法来谈。
