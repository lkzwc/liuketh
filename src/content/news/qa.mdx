干通信这行十几年，每天客服接的问题，翻来覆去就那几样：卡插上没网、显示 3G 上不去、苹果手机热点没了、用着用着断网。这些问题绝大部分自己动动手就能解决，不用等客服排期。

把多年的售后记录翻了一遍，这篇按"收到卡 → 激活 → 各种显示状态 → APN 设置 → 断网处理"的顺序，一次讲完。

## 先说激活：收到卡怎么开始用

新卡到手，先看随卡的说明书。目前主流的激活方式就三种，哪个顺手用哪个：

**公众号激活。** 说明书上一般印着公众号二维码，关注之后按教程点充值链接，充了就激活了。我们官方的公众号是【流客科技官方】，遇到问题直接在公众号里找客服。

**售后群激活。** 在靠谱商家那儿买的卡，一般都带售后群，进群按自动回复操作就能充值激活。这里多说一句：买卡一定认准能联系到售后的商家，卡这东西本身不值钱，值钱的是出了问题有人管。

**APP 激活。** 部分卡和随身 WiFi、云路由设备走 APP 充值，设备类的产品基本都在 APP 里操作。

激活完还上不了网的，往下看。

## 手机状态栏那些字母，都是什么意思

插卡之后先看状态栏显示什么，对照下表基本就有数了：

| 状态栏显示 | 什么情况 | 要处理吗 |
| ---------- | -------- | -------- |
| 5G / 4G | 正常上网 | 不用 |
| LTE | 接近 4G 的网络制式，网速不慢 | 基本不用，网络好了自动恢复 |
| GPRS | 正在传数据，属于正常显示 | 不用 |
| H / H+ | 当地信号差，手机自动降频 | 换个开阔位置，不影响使用 |
| 3G 上不了网 | 多半是 APN 没设置 | 要，见下文 APN 部分 |
| 2G | 手机太老了 | 换手机 |
| 无服务 | 卡槽制式不支持 | 换卡槽 1 试试 |
| 停机 | 流量到期或异常 | 查流量或找客服 |

展开说两个常见的。

**显示 3G 上不了网。** 这个基本出现在第一次插卡使用、充值认证完之后，原因就是 APN 没设置。设置方法在下面 APN 部分，设完重启手机，一般就好了。

**显示无服务。** 先把卡换到卡槽 1——卡槽 1 通常支持三网制式，卡槽 2 可能只支持部分制式。换了还不行，查一下自己手机是不是单制式机型，不支持这类卡。

## APN 设置：上不了网先查这个

APN 翻译成人话，就是手机上网时要告诉基站"我从哪个门进"。大部分卡插上自动就配好了，但流量卡有相当一部分需要手动设一次。设置不难，各家手机菜单名字略有差别，思路是一样的：

安卓：设置 → 移动网络/双卡管理 → 选对应的卡 → 接入点名称(APN) → 新建 APN，填入下面的值，保存后选中所建的 APN，重启。

苹果：设置 → 蜂窝网络 → 点对应的卡 → 蜂窝数据网络 → 填 APN（热点 APN 也一起填，内容保持一致）→ 返回重进设置。

APN 值按运营商填：

| 运营商 | APN 值 |
| ------ | ------ |
| 移动 | cmiot |
| 联通 | cuiot / scuiot / scuiot1（不同地区取其一） |
| 电信 | ctnet |

不知道自己卡是哪家制式的，看说明书或者问客服，别瞎猜着挨个试。

顺带说一个苹果用户的经典问题：**插了流量卡之后，设置里"个人热点"选项消失了。** 这不是手机坏了，也是 APN 没填——把上面的蜂窝数据网络里 APN 和热点 APN 都填上，退出设置重新进，热点选项就回来了。流程在 iPhone 12 上实测过，其他机型菜单可能略有差异，卡住了就找客服指导着点几下。

## 断网了，按这个顺序排查

用着用着断网，先别急，像家里宽带偶尔断电一样，手机卡也有异常的时候。按四类原因挨个排：

**一查流量。** 最常见的就是流量用完或到期停机。去后台查一下剩余流量——注意一个坑：**后台显示还剩 1G 左右，基本就是用完了**，流量统计有同步延迟，显示的不是实时的。充值之后等一会儿重启手机就恢复。

**二想最近动没动卡。** 换过卡槽、换过手机的，卡会被锁停机，这个自己解不了，联系客服走个复机流程就行，很快。

**三看是不是区域问题。** 周围人都没信号，那是基站的事，等等就好。

**四考虑卡本身。** 卡片物理损坏非常罕见，真碰上了直接联系客服申请换卡，别自己拿剪刀橡皮折腾。

## 哪些问题要找客服

自己能解决的：APN 设置、卡槽调换、流量充值。

该找客服的：停机原因查询、复机流程、换卡、以及按上面方法试完还是上不去网的。报问题的时候把**手机状态栏显示什么、什么时候开始的、最近有没有换机换卡槽**说清楚，能省一来一回的沟通。
