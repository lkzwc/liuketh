## 选点：这一步对了，后面都顺

无人零售说白了就是位置生意。同一款柜子，放对了地方月月要补货，放错了地方落灰。判断一个点位，主要看三样：

**先看人，再看货。** 封闭场景数人头：工厂有多少工人、办公室多少工位、公寓住了多少户。开放场景看每天多少人经过、多少人停留。固定人群两三百人以上，柜子基本有的做。

**停留时间比人流量更值钱。** 人流量大但都匆匆路过的，不如人少但一待八小时的。写字楼白天八小时、工厂三班倒、网吧通宵，停留越久，吃的喝的消耗越多。

**看看旁边有没有人抢生意。** 点位一百米内有便利店、小卖部的，仔细看看它们几点关门、离得多近。柜子打的就是"比你近"和"比你晚开门"——深夜十一点想买瓶水，便利店关了，柜子还亮着。

这三样看下来心里有数了，拿不准的，把点位拍照、说说情况发给我们，帮你把把关。

## 选型：柜子不是越大越好

常见的三种：

弹簧货道柜最常见，饮料袋装零食都能出，性价比高，新点位闭眼选它不会错。重力感应柜是开门自选、拿什么系统认什么，体验好，适合零食品类想摆丰富的场景，价格也贵一些。还有饮料加零食加日用的组合柜，适合工厂、公寓这种需求杂的地方。

点位小就单柜起步，人流大再考虑多台组合。别一上来就买最大的，先让数据说话。

## 安装：条件比你想的低

| 事项 | 说明 |
| ---- | ---- |
| 供电 | 普通 220V 市电，功耗跟一台冰柜差不多 |
| 网络 | 自带 4G 物联网卡，不占场地宽带 |
| 场地 | 1-2 平米平整地面，靠墙放 |
| 上门 | 送货、调试、联网、配货道，当天就能开业 |

跟场地方谈的时候，这几个条件基本都能满足，很少因为硬件卡壳的。

## 头一批货怎么配

新点位开张，品类配比给个参考：饮料占四成上下——瓶装水、可乐、功能饮料、咖啡，永远卖得动的硬通货；零食四成——辣条、薯片、饼干、坚果，冲动消费全靠它们；剩下两成放纸巾、泡面、口香糖这类顺手买的东西。

重点在后面：**上线两三周后，把后台销售数据拉出来看**。哪个卖得动就加货道，哪个摆一个月没动的果断换掉。货道就那么几十条，每条都得干活。很多柜子不赚钱，不是点位差，是一批货从头摆到尾，从来不动。

## 日常运营，其实就一件事

柜子上线后你的日常是这样的：手机后台看库存和销量，收到缺货提醒，顺路去补个货。没了。

后台能看的东西比想象中多：哪台柜子今天卖了几单、什么时段是高峰、哪个单品走量，都有记录。跑了一段时间你会发现规律——写字楼柜子下午三点最忙，工厂夜班交接是高峰，照着这个调整补货时间，效率高不少。有的系统还能发优惠券、做满减，老顾客沉寂了拉一把，都是现成的功能。
